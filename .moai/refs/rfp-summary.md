## 0.1 사업 목적·필요성·범위

- **추진배경**: 데이터 기반 의사결정 모델 정교화 + 기관 홈페이지 통폐합 + 시각화 중심 선제 경영지원
- **필요성**: 실시간 데이터 시뮬레이션 + 맞춤형 정책·안전 정보로 중소기업 전주기 성장지원
- **4대 사업범위**:
  1. 기업 성장지원 — 데이터 현행화, 가상 시뮬레이션
  2. 기업 리스크 대응 — 위험 예측 정밀화, 안전경영 가이드 자동화
  3. 정보제공 강화 — 매칭 알고리즘 고도화, 적기 알림
  4. 사용자 최적화 — 시각화 UI/UX 개편, 통합 홈페이지 이관

## 0.2 시스템 인프라 (RFP 명시)

- **OS**: Linux
- **DB**: MariaDB + Milvus (벡터 DB, RAG/매칭용)
- **WEB/WAS**: Apache + Tomcat
- **개발언어**: JAVA, JSP, Python
- **HW**: WEB 2식 + WAS 4식 + DB 2식 + 분석 1식 + 스토리지 1식 (서울 IDC)

(참고: 본 iroum-cms 프로젝트는 Vue 3.5+ + Spring Boot 3.2.x + Java 17 + PostgreSQL 16 + JWT 스택 유지. RFP는 기능 요구사항만 참고)

### 10.2 기술적용계획표 핵심 (RFP p.79~)

- 데이터 표현: HTML 4.01, **JSP 2.1**, JSON
- 프로그래밍: Java + Python
- 문자셋: UTF-8 (신규 시스템 우선)
- DB: RDBMS 적용 (Maria/Milvus 운영기존)
- 표준프레임워크: **전자정부 표준프레임워크 적용**
- 웹접근성: KWCAG **2.1** (기술적용표 / 단 본문 COR-001은 2.2)

## 11. iroum-cms 적용 시 주의 사항

본 iroum-cms는 자체 프로젝트로 **기술 스택은 SPEC-CMS-001~005에 명시한 그대로 유지**합니다 (Vue 3.5+ + Spring Boot 3.2.x + Java 17 + egovFrame v5.0.0 + PostgreSQL 16 + JWT). RFP는 **기능 요구사항만** 참고합니다.

| RFP 명세 | iroum-cms 적용 |
|---|---|
| MariaDB + Milvus | PostgreSQL 16 (CMS) + 별도 SPEC에서 Milvus 옵션 추가 (AI/ML 트랙) |
| JSP 2.1 | Vue 3.5 SPA 유지 (관리자/사용자 모두) |
| 상급기관 SSO API | JWT 유지, SSO 연동은 별도 옵션 SPEC |
| Apache + Tomcat | Spring Boot 내장 Tomcat 10 + Nginx reverse proxy |
| KWCAG 2.1 (기술표) vs 2.2 (본문) | **KWCAG 2.2 AA** 적용 (기존 SPEC 그대로) |
| 통합파일서버 SER-006 | Local FS 또는 객체 스토리지 (선택) |
